Field Analyzer preview

Simulates the six-page main carousel this device could have: Radio, Tools (Probe/Sweep/Cell, proposed), Analyze (Meter/Waterfall/Scope/Captures/Nodes, already flashed), Channel, GPS, System. Drive it with the same four keys the physical unit uses.

Analyze is real — this is what's on the device right now. Tools is a proposal (operator idea, 2026-09-03: apply the same hub pattern to Probe/Sweep/Cell, freeing up two main-carousel slots) — nothing below reflects real firmware for it yet.

Waterfall's frequency axis and Enter-to-repeat are also real (operator idea, 2026-09-04, shipped and hardware-confirmed the same day — "waterfall works amazing"): a labeled MHz axis under the plot (lo/center/hi + reference ticks, since Waterfall shows history across many rows, not one live scan the way Sweep/Cell's own position-marker bar does), a top-row "SCANNING" badge opposite the hit counter, and reaching the same repeat-Sweep toggle the Tools/Sweep card's R key already has straight from this page — it's Sweep's own history view, so watching it fill in without a detour to Tools is the point.

Meter's SNR line, right-column channel params, and bar gauge are also real (operator idea, 2026-09-04: "it's a little bland" — shipped and hardware-confirmed the same day). SNR and SF/BW/CR are real data this page already had access to (CaptureSummary) and never showed, watch-sourced only since Scope never demodulates a signal to have either. The bar is a filled gauge, not drawFreqBar()'s position marker — signal strength genuinely is a quantity, unlike frequency, which is a location — ranged -120/0dBm (widened from an initial -120/-30 same day, after a real -16dBm reading clipped flat against that ceiling). Deliberately no strength-tier colour-coding (green=strong/red=weak): no such convention exists anywhere in this codebase, and inventing thresholds would be the fabricated-meaning problem this project is otherwise careful about.

Not pixel-exact — IBM Plex Mono stands in for the device's fixed 6×8/12×16 bitmap font. Analyze's real coordinates are from src/ui_pages.cpp; Radio/Channel/GPS/System/Probe/Sweep/Cell are simplified placeholders here (their own real layouts are unchanged by this proposal — see ui-panel-set.html).
